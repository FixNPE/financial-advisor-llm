UI direction memo · NexWealth AI

From seven pages to one conversation

A look at how the strongest consumer financial-advice apps structure their interface, and what closing that gap would actually cost in this codebase.

01What the market is doing

Every competitive AI-native advisor collapses onto a single conversational surface. Structured data — charts, gauges, decision cards — renders inside the message stream instead of behind separate navigation.

Cleo
Chat is the entire app. Spend breakdowns and roasts render as cards mid-conversation, no tabs.
Copilot Money
Dashboard-first, but the "Ask Copilot" chat overlays as a full-screen sheet with inline charts, not a side drawer.
Origin
One chat thread per financial topic; a slim right-side "workspace" pins whichever plan you're actively editing.
Monarch
More dashboard-led, but AI answers appear as expandable inline cards on the same screen — never a page navigation.

The read

NexWealth's structure — a persistent sidebar routing between seven separate pages, with chat bolted on as a slide-in panel — is the pattern the market has moved away from. The fix isn't a new page. It's inverting which surface is primary.

04Is this too much change?

Honest answer: it's a real UI rewrite, not a redesign pass — but it doesn't touch the parts of this codebase that are actually hard to get right.

LayerChange requiredEffort
src/advisor/ — orchestrator, domain math, agents, RAG, tools None. Cards render existing PipelineResult / AdvisorAnswer objects — this is a rendering change, not a logic change. none
app/components/ — dashboard.py, floating_chat.py Repurpose as card renderers callable from inside a message loop, instead of full-page bodies. moderate
app/pages/ — 7 page files Collapse into one page with a message stream; old page bodies become card templates. Streamlit's st.chat_message already supports arbitrary rich content (Plotly, buttons) per message, so this stays in-stack. largest chunk
session.py — session-state model Shift from "current page" as the unit of state to "conversation turn." New: turn history, pinned-card state. moderate
theme.py — sidebar nav Shrink from 7 destinations to ~3 (Home/empty-state, Chat, History). Right rail is new. small

My recommendation: don't do it as one cutover. Ship it in three phases — (1) merge FinAdvisor + Recommendations + Report into one thread with inline cards, since that's the single flow users actually complete end-to-end; (2) fold Risk Profile and Dashboard in the same way; (3) add the pin-to-rail canvas last, once you know which cards people actually want kept in view. Phase 1 alone gets you most of the perceived "fragmented" feeling gone, and it's scoped enough to sanity-check the pattern before committing further.

Wireframes are structural only — no visual design applied. Palette and type here belong to this memo, not to a proposed NexWealth visual refresh.
